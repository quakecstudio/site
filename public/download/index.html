Download QuakeC Studio 2026.11.2

Free and open source under GPL-3.0-or-later. Every package includes the IDE (quakec-studio), its game engine (quakec-engine), the command line (quakec-ide) and the language server (quakec-lsp). You also need your own copy of Quake or the free LibreQuake; see Installing.

macOS

macOS 11 or later, Apple silicon

brew install --cask quakecstudio/tap/quakec-studio
  • Installer (.pkg)

Signed and notarized. Installs to /Applications and links quakec-ide and quakec-lsp into /usr/local/bin.

Windows

x64 or arm64

  • x64 installer (.msi) · portable (.zip)
  • arm64 installer (.msi) · portable (.zip)

The programs inside are signed by Smoke Turner, LLC. The MSI itself isn't, so Windows may warn before it runs. The MSI installs for every user, adds a Start menu shortcut and puts the folder on PATH.

Coming to winget as SmokeTurner.QuakeCStudio once the package is accepted.

Linux

x86_64 or aarch64, glibc 2.35 or later, X11 or Wayland

Add the repository at packages.quakecstudio.com, then run:

sudo apt-get install quakec-studio
sudo dnf install quakec-studio
  • x86_64: .deb · .rpm · .AppImage · .flatpak
  • aarch64: .deb · .rpm · .AppImage · .flatpak

The repository's metadata and the rpm are signed with the key packages.quakecstudio.com serves.

Verify a download

The release's SHA256SUMS lists every package's SHA-256. Every package also has a build-provenance attestation, which the GitHub CLI checks:

gh attestation verify <file> --repo quakecstudio/editor \
  --signer-workflow quakecstudio/editor/.github/workflows/reusable-build.yml

The app doesn't check for updates. Update through your package manager, or download a new version from here. Release notes and older versions are on GitHub Releases.
