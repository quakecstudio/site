What's new

The highlights of each release. The release notes on GitHub have every change and every package. To update, see Updating.

2026.11.2

Agents

  • Use Claude Code. The agent panel can run Claude Code, or any agent that speaks the Agent Client Protocol, in place of a model provider, with the IDE's tools connected to it. See Use Claude Code or another agent.
  • What Does This Code Do? on a selection in the editor asks the agent for a plain explanation.
  • The agent's replies are drawn as Markdown: headings, lists, code, tables and links.
  • project.reference gives any agent, over MCP too, a reference on writing QuakeC: the language, what the engine calls, how a monster is written, models, maps, and tests.
  • An outside agent's map edits over MCP are made at once, as its file edits are; undo or Restore checkpoint takes them back.

Maps

  • New Random Map makes a playable level: rooms of seven shapes joined by passages, stairs and doors, from a start to an exit, with lights, monsters, weapons and a key. See A random map.
  • map.build_room and map.build_passage build one room of a shape from id's levels, or the passage between two, with one command each.
  • map.brushes and map.summary list a map's brushes and sum a map up, and map.play_from_here says which entities stand in the dark and can start the game paused.
  • map.issues reports an entity placed past the 4096-unit edge the game can send.

Models

  • The model.* commands read a .mdl and change it: copy one from the game, recolour, export and set its skin, scale, move, and rename, remove or add frames.
  • model.import makes a .mdl from an .obj, .iqe, .md5mesh, .smd or .fbx (text or binary). See Models.
  • Play puts the project's own models, sounds and other assets where the game reads them.

The window and the game

  • A Welcome page with no project open: find Quake's files, start a project, press Play.
  • New Project… asks which game the mod is for in one dialog, choosing the one your install holds.
  • The Quake files guide accepts a folder inside the install, such as id1.
  • The status bar's error and warning counts open Problems, and the command line lists the commands that match as you type.
  • The game runs quake.rc before the first map, and takes the later engines' options from its console: r_lerplightstyles, gl_zfix, r_litwater and sv_protocol.

2026.11.1

The first release, on 20 November 2026, for macOS (Apple silicon), Windows and Linux.

  • The editor: go to definition, references, rename, diagnostics, completion and hover for vanilla QuakeC and FTEQCC; splits, folding, an outline, project search, quick fixes, a formatter, git, a terminal, your own keys and Vim mode.
  • The compiler: its own, with no outside toolchain. It compiles id's QuakeC 1.01 to the same bytes as id's qcc, and the rerelease's codebases to FTEQCC's statements.
  • The play loop: save, compile and see the change in the running game, with breakpoints and the game's entities to inspect, in QuakeC Studio's own engine.
  • The agent: a panel with diff review, checkpoints and the same commands you use, also over MCP and the command line.
  • The map editor: brushes, entities, textures, and its own BSP, vis and light compilers, sharing the project and the play loop.
  • Export: a mod as a zip players can install, optionally in a PAK, never with Quake's own data.

Not supported yet: GMQCC, CSQC and MenuQC.
