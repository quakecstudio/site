Keys

The keys you will use most, written for macOS. On Windows and Linux, Cmd is Ctrl, and Alt is the Option key on a Mac. The palette (Cmd+Shift+P) shows each command's key beside its name, and the editor's full keymap lists every default key and where it comes from.

Everywhere

KeyWhat it does
Cmd+Shift+PThe command palette: every command the IDE has, searched by name
Cmd+POpen a file of the project by name
Cmd+;The command line, which runs a command by its id and asks for each value it needs
Cmd+1, Cmd+2, Cmd+3, Cmd+4Give the keyboard to the editor, the left, right or bottom panel
Cmd+Shift+FSearch the project
Ctrl+TabSwitch to another open file
Cmd+\Split the editor to the right
Cmd+Alt+\Split the editor down
Cmd+Shift+\Close the split
Cmd+Shift+BShow or hide the outline of the file
Cmd+Alt+GRun the game in the window's Game tab, or in its own window beside it, from the next Play
Ctrl+Shift+`A new terminal
Cmd+Alt+SRecord a checkpoint of the project
Cmd+,Settings

The map editor

These follow TrenchBroom's default keys where TrenchBroom has the same action.

KeyWhat it does
W A S D, Q XFly the 3D view forward, left, back and right, up and down
B, C, V, M, L, P, HThe brush, clip, vertex, move, measure, shape and hull tools
EnterMake the brush drawn, or cut with the clip plane
EscDrop the tool's work in hand, then the selection
arrows, Page Up, Page DownMove the selection a grid step
Alt+Left, Alt+RightTurn the selection a quarter turn
1 to 9Set the grid from 1 to 256 units; + and - double and halve it
Cmd+DDuplicate the selection
DeleteDelete the selection
Cmd+UFrame the selection in the 3D view
Cmd+G, Cmd+Shift+GGroup and ungroup
Cmd+I, Cmd+Alt+I, Cmd+Shift+IIsolate the selection, hide it, show everything

Cmd+BCompile the map with the chosen profile
Cmd+Shift+KCheck the map for leaks

With faces picked, the arrows and Page Up and Page Down move and turn their textures instead: Shift for a coarse step, Cmd for a fine one.

Vim mode

To edit with Vim's keys, set editor.key_mode to vim (Settings), then start the app again. In settings.toml:

[editor]
key_mode = "vim"

The editor starts in Normal mode, with Vim's insert and visual modes, motions, operators, counts, registers and ..

Changing a key

Write keymap.toml in the app's config folder: on macOS ~/Library/Application Support/QuakeC Studio, on Windows %APPDATA%\QuakeC Studio, on Linux ~/.config/quakec-studio. Each binding names its keys and a command from the palette:

[[binding]]
keys = "secondary-shift-b"
command = "project.build"

secondary is Cmd on macOS and Ctrl elsewhere; the other modifiers are ctrl, alt and shift. Your binding wins over a default that uses the same keys. The change takes effect at once, and a binding the app cannot read is reported while the rest still apply.
