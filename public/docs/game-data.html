Your Quake game data

QuakeC Studio does not include Quake's game files, and never copies them: you need your own copy of the game, and the IDE reads it where it is installed. This page says what it looks for, where the stores put the game on each system, and how to get it onto a Mac.

What you need

You haveFilesWhat you can do
The original game (1996), registeredid1/pak0.pak and id1/pak1.pakEverything: mods for the original game and its mission packs (hipnotic, rogue)
The shareware episodeid1/pak0.pak onlyEpisode 1 only; the IDE reports id1/pak1.pak as missing
The 2021 rerelease (Quake Enhanced)rerelease/id1/pak0.pak, QuakeEX.kpf, and hipnotic, rogue, dopa, mg1Mods for the rerelease; its id1 has only its own pak0.pak

Steam and GOG sell both the original game and the rerelease:

  • Steam's install has the original game at the top and the rerelease in its rerelease folder.
  • GOG's Quake Enhanced has the rerelease at the top (QuakeEX.kpf, id1, hipnotic, rogue, dopa, mg1, mg3, ctf) and the original DOS game in its dos folder. The IDE reports both.
  • The Epic Games Store and Xbox Game Pass sell only the rerelease, so the IDE reports the original game's id1/pak0.pak and id1/pak1.pak as missing for those installs.

Names are matched in any case: Steam's original install uses Id1/PAK0.PAK.

The IDE checks each file against its published size and checksum. A file it does not recognise is still used if it is a valid PAK archive; the rerelease's files change with every update, so that is normal for the rerelease. A file that is not a valid archive is reported as damaged.

Getting the game onto a Mac

Both stores sell Quake for Windows only, but the game data is the same on every system. Two ways to get it, neither of which needs Windows:

GOG, with innoextract. Download the offline backup installer from your GOG library ("Quake" for the original game, "Quake Enhanced" for the rerelease), not the GOG Galaxy installer. If it comes in several parts, keep them in one folder. Then:

brew install innoextract
innoextract --output-dir ~/Games/quake-gog ~/Downloads/setup_quake_*.exe

innoextract writes the game into an app folder inside the output folder. Choose ~/Games/quake-gog (or its app folder) in QuakeC Studio.

Steam, with steamcmd. steamcmd is Valve's command-line Steam client. Make an empty folder for the game, then:

brew install steamcmd
steamcmd
Steam> force_install_dir /Users/<you>/Games/quake-steam
Steam> login <your Steam user name>
Steam> @sSteamCmdForcePlatformType windows
Steam> app_update 2310 validate
Steam> quit

2310 is Quake's Steam app id; the download includes the rerelease in its rerelease folder. steamcmd needs an absolute path, not ~. Choose the folder in QuakeC Studio; it recognises a steamcmd download.

What QuakeC Studio does with it

Nothing is written into your install, and nothing is copied out of it. To run your mod, the IDE makes a run folder inside your project with a link to the install's id1 and a link to your mod's build output, and starts the game there. The links are symbolic links on macOS and Linux and junctions on Windows; neither needs administrator rights.

When you export a mod for players, the IDE refuses any file that is a copy of one of the game's own, so a mod you share never carries id Software's data.
