Install

QuakeC Studio is free and open source (GPL-3.0-or-later), with no account. It runs on macOS 11 or later on Apple silicon, on Windows for x64 and arm64, and on Linux for x86_64 and aarch64. Every package is on the download page; this page says how to install each one, how to update, and how to remove it.

Every package holds four programs: the app, quakec-studio; the game it runs your mod in, quakec-engine; the command line, quakec-ide (Command line); and the language server for other editors, quakec-lsp.

QuakeC Studio does not include Quake's game files. To play your mod you need your own copy of Quake, or the free LibreQuake. See Your Quake game data.

macOS

With Homebrew:

brew install --cask quakecstudio/tap/quakec-studio

Or download quakec-studio-<version>-macos-arm64.pkg and open it. The installer is signed and notarized by Apple. It puts QuakeC Studio in /Applications, replacing any version already there, and links quakec-ide and quakec-lsp into /usr/local/bin.

There is no build for Intel Macs.

Windows

Download the MSI for your processor, quakec-studio-<version>-windows-x64.msi or -windows-arm64.msi, and open it. It installs for every user under Program Files, adds a Start menu shortcut, and puts the folder on PATH, so quakec-ide and quakec-lsp work in a new terminal.

The programs inside are signed, but the MSI itself is not, so Windows may call its publisher unknown when it asks to install it.

The portable .zip holds the same programs with no installer: unzip it anywhere and run quakec-studio.exe. Nothing needs the Visual C++ Redistributable.

QuakeC Studio has been submitted to winget. Until it is accepted, this command does not work yet:

winget install SmokeTurner.QuakeCStudio

Linux

On Debian and Ubuntu, add the APT repository at packages.quakecstudio.com and install:

curl -fsSL https://packages.quakecstudio.com/gpg/quakecstudio.asc \
  | gpg --dearmor \
  | sudo tee /usr/share/keyrings/quakecstudio-archive-keyring.gpg > /dev/null

echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/quakecstudio-archive-keyring.gpg] https://packages.quakecstudio.com/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/quakecstudio.list > /dev/null

sudo apt-get update && sudo apt-get install -y quakec-studio

On Fedora and RHEL, add the DNF repository and install:

sudo tee /etc/yum.repos.d/quakecstudio.repo << 'EOF'
[quakecstudio]
name=QuakeC Studio
baseurl=https://packages.quakecstudio.com/rpm/$basearch/
gpgcheck=1
repo_gpgcheck=1
gpgkey=https://packages.quakecstudio.com/gpg/quakecstudio.asc
enabled=1
EOF

sudo dnf install -y quakec-studio

The repository's metadata and its rpm packages are signed with the key at https://packages.quakecstudio.com/gpg/quakecstudio.asc, fingerprint B00D 6EBB BD27 0E2A 6C12 F473 0320 6F03 F365 A966.

Or download a package for x86_64 or aarch64:

PackageHow to install it
.debsudo apt install ./quakec-studio-<version>-linux-x86_64.deb; needs glibc 2.35 or later (Ubuntu 22.04, Debian 12)
.rpmsudo dnf install ./quakec-studio-<version>-linux-x86_64.rpm
.AppImagechmod +x the file, then run it
.flatpakflatpak install --user ./quakec-studio-<version>-linux-x86_64.flatpak, then flatpak run com.quakecstudio.QuakeCStudio; it uses the Freedesktop 25.08 runtime

The deb and rpm put quakec-studio, quakec-ide and quakec-lsp in /usr/bin. The app needs Vulkan or OpenGL, and X11 or Wayland.

Check a download

Each release has a SHA256SUMS file, and each package is attested by the GitHub workflow that built it. With the GitHub CLI:

gh attestation verify quakec-studio-<version>-windows-x64.msi --repo quakecstudio/editor \
  --signer-workflow quakecstudio/editor/.github/workflows/reusable-build.yml

First launch

With no project open, the app shows its Welcome page, in three steps:

  1. Find Quake's files. The app looks for Quake where Steam, GOG and the Heroic launcher install it, and says what it found. If it found nothing, press Set Up Quake Files… and choose the folder that holds id1.
  2. Start a project. New Project… makes a mod from the game's own QuakeC; Open Folder opens one you have.
  3. Press Play. The app builds your mod and starts the game.

Getting started walks through all three.

Updating

You update QuakeC Studio with what installed it; the app never downloads or installs a release itself.

  • Homebrew: brew upgrade --cask quakec-studio.
  • winget, or the MSI: winget upgrade SmokeTurner.QuakeCStudio, which also updates an MSI you installed by hand. A new release can take a few days to reach winget; until then, download the new MSI.
  • APT: sudo apt update && sudo apt install --only-upgrade quakec-studio, or with the rest of your system.
  • DNF or YUM: sudo dnf upgrade quakec-studio, or sudo yum upgrade quakec-studio.
  • A downloaded package: install the new one. The macOS installer and the MSI replace the version that is there; unzip a new portable zip in place of the old one, and replace an AppImage or a Flatpak bundle with the new file.

Help > Check for Updates… asks whether there is a later release, and tells you which of these fits your install: the command to copy, or Download, which opens the release's page in your browser. The app asks only when you choose that item. To have it also ask as it starts, at most once a day, set updates.check = "daily" in your settings; the status bar then says Update available when there is one, and Skip This Version stops it for that release. Privacy says exactly what the check sends.

What's new lists what each release changed.

Uninstalling

  • macOS, with Homebrew: brew uninstall --cask quakec-studio.
  • macOS, from the installer: remove the app and its two links, and tell macOS to forget the package: 
    sudo rm -rf "/Applications/QuakeC Studio.app"
sudo rm -f /usr/local/bin/quakec-ide /usr/local/bin/quakec-lsp
sudo pkgutil --forget com.quakecstudio.QuakeCStudio
  • Windows: remove QuakeC Studio in Settings > Apps, or delete the portable folder.
  • Linux: sudo apt remove quakec-studio, sudo dnf remove quakec-studio, flatpak uninstall com.quakecstudio.QuakeCStudio, or delete the AppImage.

Uninstalling leaves your settings, logs and caches. Remove these folders too for a clean slate:

OSFolders
macOS~/Library/Application Support/QuakeC Studio, ~/Library/Caches/QuakeC Studio, ~/Library/Logs/QuakeC Studio
Windows%APPDATA%\QuakeC Studio, %LOCALAPPDATA%\QuakeC Studio
Linux~/.config/quakec-studio, ~/.local/share/quakec-studio, ~/.cache/quakec-studio, ~/.local/state/quakec-studio

Your projects are yours and are never touched. Each keeps its own settings and agent threads in its .quakec-studio folder.
