FAQ

Do I need Quake?

To play your mod, yes: QuakeC Studio does not include Quake's game files. The original game, the 2021 rerelease or the shareware episode will do, from Steam, GOG or elsewhere, and the free LibreQuake data works too. Writing, building and unit-testing QuakeC needs no game; scenario tests and Play do. See Your Quake game data.

What does it cost?

Nothing. QuakeC Studio is free and open source under the GPL, version 3 or later, with no account. The agent's model provider, if you use one, is yours to choose and pay for; a local Ollama model costs nothing.

Which systems does it run on?

macOS 11 or later on Apple silicon, Windows on x64 and arm64, and Linux on x86_64 and aarch64. There is no build for Intel Macs. See Install.

Which QuakeC does it read?

Two dialects: vanilla, the QuakeC id's own compiler reads, and FTEQCC's, which most mods use today and the rerelease is written in. A project names its dialect in quakec.toml (Open a folder). GMQCC's dialect and client-side and menu QuakeC (CSQC and MenuQC) are not supported yet.

Does it replace my compiler?

It has its own, so you need no other tool. It compiles id's QuakeC 1.01 to the same bytes as id's qcc, and the rerelease's code to the same statements as FTEQCC. A compatibility list shows how it does on public mods.

Does it work with TrenchBroom?

Yes. The map editor opens the same .map files, with brushes in the standard and Valve 220 forms, and keeps TrenchBroom's groups, linked groups and layers. Its keys and tools follow TrenchBroom's where TrenchBroom has the same action, so you can move between the two. When another program changes the open map on disk, the editor reads it again, or asks first when you have unsaved edits.

Does it work offline?

Yes. Everything but the agent works with no network, and the agent does too with a local Ollama model. The only other request the app can make is for a starter's files when you make a new project. See Privacy.

Do I have to use the agent?

No. Until you set up a provider or an outside agent, the agent sends nothing anywhere and does nothing.

Can I use it from my own editor?

Yes: quakec-lsp gives any editor with an LSP client the same diagnostics, navigation, rename and completion, and quakec-ide builds and tests from a terminal or CI. See Command line.

Can I change the keys?

Yes, any of them, in keymap.toml, and the editor has a Vim mode. See Keys.

How do I update it?

The app does not check for updates. Homebrew, APT and DNF update it with the rest of your system; otherwise install the new package. See Updating.

Is it made by id Software?

No. QuakeC Studio is an independent fan project, not affiliated with or endorsed by id Software, ZeniMax Media or Bethesda.

Where do I report a problem?

On GitHub; see Reporting a problem for what to include. Questions are welcome on Discord.
