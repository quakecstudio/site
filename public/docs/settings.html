Settings

QuakeC Studio has a few settings, kept in plain TOML files. Cmd+, opens yours in the editor.

Where settings are kept

  • Yours are in settings.toml in the app's config folder: on macOS ~/Library/Application Support/QuakeC Studio, on Windows %APPDATA%\QuakeC Studio, on Linux ~/.config/quakec-studio.
  • A project's are in .quakec-studio/settings.toml in the project's folder, and win over yours for that project.

Each file sets only what it names, as a TOML table:

[appearance]
theme = "light"

[editor]
key_mode = "vim"

The settings.list, settings.get, settings.set and settings.reset commands read and change them from the palette, the command line and the agent.

Every setting

KeyDefaultWhat it does
appearance.theme"dark"The colour theme: dark or light.
log.filter"info"What the log records, as RUST_LOG directives such as debug or info,qc_sema=debug. RUST_LOG wins when it is set. See Where the log is.
game.foldernoneThe folder Play reads Quake from, as you chose it in the Quake files guide. When it is not set, the first install found is used, and a folder that no longer holds a game is passed over. See Your Quake game data.
agent.profile"write"What the agent may do: ask (only read), write (read and edit unasked, ask before anything else) or full (everything unasked). See What it may do.
agent.tool_permissions{}Rules for the agent's tool calls, over the profile: a default of allow, ask or deny, and tools.<command id> with its own default and allow, ask and deny patterns, matched with * and ? against the paths a call names. deny wins, then ask, then allow.
agent.external[]The outside agents the agent panel can run over the Agent Client Protocol, each with a name, the command that starts it, and its args and env. The panel's Use Claude Code adds Claude Code. See Use Claude Code or another agent.
editor.key_mode"standard"How the code editor reads keys: standard, or vim for Vim's modes, motions, operators, counts, registers and .. See Vim mode.

Examples

Ask before the agent changes progs.src, and never let it change anything under maps/, in a project's .quakec-studio/settings.toml:

[agent.tool_permissions.tools."edit.stage_change"]
ask = ["progs.src"]
deny = ["maps/*"]

Run an outside agent of your own over ACP:

[[agent.external]]
name = "My agent"
command = "my-agent"
args = ["--acp"]

Other things are kept in files of their own: the agent's model provider in agent.json in the app's data folder (its key in the system keychain), your keys in keymap.toml, and a map's compile profiles in the project's compile-profiles.toml.
