QUAKEC STUDIO

An IDE for QuakeC, the scripting language behind id Software's original Quake. Write code, save, and see it change in the running game. The compiler, the debugger, an agent and a map editor are built in.

Version 2026.11.2 · free and open source (GPL-3.0) · macOS, Windows, Linux

What it does

Save and see it in the game

Press Play and the mod runs in QuakeC Studio's own engine, in the Game tab or its own window. Each save compiles the project and reloads its code into the map that's already running. Fields and globals carry over, and if something would be reset the IDE tells you which and offers a map restart.

81 ms from save to game (95th percentile, on the reference Mac).

Pause and click any entity to read or edit its fields while the game waits.

The play loop

A debugger that stops the game

Set a breakpoint in a monster's AI and the running map stops on that line. Step in, over and out, by statement or by frame, with the call stack, watches and an evaluator in the IDE.

Debugging

An agent that proves its work

Ask for a change and the agent uses the same commands you do. It edits, compiles and runs the project's tests and scenarios in the game, and a run only finishes once the build is clean and every test passes. You accept or reject each hunk it hands back, and every run leaves a checkpoint you can roll back to.

Works with Anthropic, any OpenAI-compatible endpoint, a local Ollama, or Claude Code. Keys stay in your system keychain. The same tools are available to any agent over MCP.

The agent · MCP

A map editor with its own compilers

Brushes, entities and textures share the project with your code, and the entity list comes from your own QuakeC. Compile with QuakeC Studio's own qbsp, vis and light, which include ericw-tools' sunlight, bounce and coloured light, and the 3D view shows the map lit the way the game draws it. Then press Play from here and you start where the camera is.

Uses TrenchBroom's keys, groups and layers. Reads standard and Valve 220 .map files.

The map editor

A compiler that knows QuakeC

It ships its own compiler, so there's nothing else to install. It builds id's 1.01 QuakeC to the same bytes as id's qcc, and the rerelease's code to FTEQCC's statements. Errors appear as you type. Go to definition, references, rename, hover docs for builtins, inlay hints, quick fixes and a formatter work across your whole progs.src, for the vanilla and FTEQCC dialects.

Also in the box

  • Tests in the game

    Unit tests are test_ functions. Scenarios are scripted runs of the real game that play the same way every time. Run them all with one command.

  • Command line and LSP

    quakec-ide builds, checks, tests and runs any command from a shell or CI. quakec-lsp brings the same language features to VS Code, Zed and Neovim.

  • MCP server

    quakec-ide mcp gives Claude Code or any other MCP client the same commands, on the project or on the open window.

  • Starters and export

    Start from id's 1.01 QuakeC or the rerelease's. When the mod is done, export a zip players can install, optionally as a PAK, with none of id's files in it.

  • Seven engine targets

    Builtin tables for vanilla Quake, QuakeSpasm, Ironwail, vkQuake, FTEQW, DarkPlaces and the 2021 rerelease, so you're warned when a builtin doesn't exist on your target.

  • Git and a terminal

    Changed hunks, commits, branches and blame, project tasks and terminal tabs, all in the same window.

  • Your keys

    Every command has a key and you can change any of them. Vim mode, dark and light themes, and higher contrast are all available.

  • Offline, no account

    No telemetry and no sign-in. The only network requests go to the model provider you pick and to GitHub, once, for a starter's files.

Get it

Requirements

  • macOS 11 or later on Apple silicon
  • Windows on x64 or arm64
  • Linux x86_64 or aarch64, glibc 2.35 or later, X11 or Wayland

Bring your own copy of Quake: the original or the 2021 rerelease, from Steam, GOG or elsewhere. The app finds it where it's installed. Don't own it? The free LibreQuake works too.

Install

brew install --cask quakecstudio/tap/quakec-studio

On Linux, use the APT and DNF repository at packages.quakecstudio.com. Every package is also on the download page.
