QUAKEC STUDIO

A modern IDE for QuakeC, the scripting language behind id Software's original Quake. Write code, press Play and watch it change in the running game, with a compiler, an agent and a map editor built in.

Planned features

  • Press Play

    Save and see the change in the running game in about a second. Pause, click any entity, and inspect or edit its fields.

  • Its own compiler

    A QuakeC compiler built in, so there's no outside toolchain to install. Errors show up as you type, next to the line that caused them.

  • Knows QuakeC

    Go to definition, find references, rename and hover docs for builtins like spawn and traceline, across your whole progs.src.

  • An agent that tests

    A built-in agent uses the same commands you do: it edits, compiles and runs scenarios, then hands you each change to accept or reject. Also over MCP.

  • Map editor

    Brushes and entities in the same project as your code, with entity definitions read from your QuakeC. Compile the map and play from where you're standing.

  • Mac, Windows, Linux

    One native app, written in Rust. Bring your own copy of Quake; the Steam and GOG releases are found for you.
