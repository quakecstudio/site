Privacy Policy

Effective 21 November 2026

This policy covers the website at quakecstudio.com, the package repository at packages.quakecstudio.com, and the QuakeC Studio app. All three are run by Smoke Turner, LLC ("we"). In short, there's no account, no cookies, no analytics and no telemetry, and we don't sell or share personal information.

The website

The site is a set of static pages served by Amazon Web Services (Amazon S3 and CloudFront). To deliver a page, AWS necessarily handles your IP address and the request your browser sends. We haven't turned on CloudFront's access logs, so we keep no record of who visited or which pages they read.

The site sets no cookies, runs no analytics or advertising, and loads nothing from other sites. Its fonts, scripts and images are all served from quakecstudio.com.

The visitor counter. On your first visit, the page asks our server to add one to a single running total, and your browser saves a flag named qcs.counted in its local storage so it isn't counted again. The request carries no identifier, and all we store is the total itself. The counter's server keeps error logs for 14 days. Clear your browser's site data to remove the flag.

Copy buttons in the user guide write to your clipboard when you press them, and never read from it.

Downloads and package managers

Packages are downloaded from GitHub Releases, and the source, issues and discussions are on GitHub. GitHub's privacy statement covers what GitHub collects. The APT and DNF repository at packages.quakecstudio.com is served the same way as this site, also with no access logs. Homebrew, winget and your Linux distribution's tools have their own privacy practices. Homebrew, for example, collects anonymous analytics unless you turn them off.

The app

QuakeC Studio runs on your computer, offline, with no account and no telemetry. It doesn't send us your code, your files or how you use it. It makes a network request only when you ask for something that needs one:

  • The agent sends your requests, plus the code and project context it needs, to the model provider you configure: Anthropic, an OpenAI-compatible endpoint, or a local Ollama. That provider's own privacy policy and terms apply. Your API keys stay in your operating system's keychain.
  • Use Claude Code starts Claude Code through npx, which downloads its adapter from the npm registry. Claude Code then works under your own Anthropic account.
  • New project downloads a starter's files from GitHub at a pinned version.

The user guide's Privacy page lists every request the app can make and the settings that control them.

If you write to us

If you email us or open an issue, we use what you send only to reply and to work on what you raised. We keep emails only as long as they're needed for that. Anything you post in a public GitHub issue or discussion is public.

Children

The site and the app aren't directed at children under 13, and we don't knowingly collect their personal information.

Your choices and rights

We hold almost no personal information: at most, an email you sent us. You can ask what we hold about you, ask for a copy, or ask us to correct or delete it, by writing to the address below. We won't treat you differently for asking.

Changes

If this policy changes, we'll update it here with a new effective date. The site's history, including every past version of this page, is public on GitHub.
